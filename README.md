# 별빛추모 (Starlight Memorial)

반려견 추모 사이트

- HTML + Tailwind CSS + Alpine.js
- Supabase (Auth, Database, Storage)
- GitHub Pages 배포

## 기능

- 구글 로그인
- 추모관 생성/관리 (별빛 무료 1개 / 별빛 플러스 10개)
- 사진·영상 업로드 (용량 제한)
- 방명록
- 반려견 이름 검색
